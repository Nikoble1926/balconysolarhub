“Non-compliant” is the register’s own word, not ours. Each entry’s page carries the same sentence: “This device has been assessed by ENA’s engineers as non-compliant. Distribution network operators are unlikely to accept this equipment on their networks”. The register explains that the status “is assigned by ENA appointed evaluators”. Seven of the twenty-three entries above, all from UKSOL Ltd, instead carry “Compliant” — the register’s own assessment that network operators will accept the equipment, which is not the same as certification to the Interim Product Specification v2.
